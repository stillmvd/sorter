# Звуки Sorter

Положи сюда файлы `.wav` / `.mp3` / `.ogg` с этими именами — подхватятся при сборке. Нет файла — действие молчит.

| Файл | Когда | Каким должен быть |
|------|-------|-------------------|
| `place` | карта легла в стопку | короткий мягкий «шлёп»/тап по картону, 60–120 мс, без хвоста |
| `trash` | карта ушла в корзину | сухой «ффт»/смятие бумаги или короткий свуш вниз, до 200 мс |
| `undo` | ход забран | обратный свуш/«вжух» вверх или реверс `place`, до 200 мс |
| `new_pile` | создана новая стопка | светлый короткий «динь»/поп, 100–200 мс |
| `batch` | пачка со стола легла в стопку | несколько быстрых шлепков подряд / перетасовка, до 300 мс |
| `defer` | карта ушла в конец колоды (Tab) | тихий шорох/скольжение карты, до 150 мс |
| `error` | ход не удался | глухой низкий «бум»/отказ, без резкости, до 200 мс |
| `empty` | колода разложена целиком | маленький тёплый аккорд/финальный шорох, до 1 с |

Звуки частые — главное короткие атаки и тишина после них, громкость ниже музыки.
