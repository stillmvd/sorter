# Data Model: Дубли

## Fingerprint — отпечаток видео

| Поле | Тип | Правило |
|------|-----|---------|
| path | text PK | полный путь файла (карта колоды — `deck_path\file_name`, файл стопки — его путь) |
| size, mtime | integer | изменились — отпечаток пересчитывается |
| sha256 | blob(32) | хеш содержимого |
| duration_ms, width, height, bitrate, rotation | integer | сведения; ширина/высота с учётом поворота |
| box | text | срез чёрных полей `t,b,l,r` в долях, если был |
| frames | blob | кадровые хеши u64 LE, 4 в секунду |
| audio | blob | звуковые хеши u32 LE, шаг 256/5512 с; пусто — нет звука |
| semantic | blob | векторы f32 × 768, 1 в секунду |
| mean | blob | средний смысловой вектор (для предфильтра) |
| state | text | `ok` / `failed` (не прочиталось — не повторять, пока файл не изменится) |

Индекс кандидатов (в памяти): 4 куска × 16 бит кадровых хешей → список `(path, t)`; звуковые хеши → `(path, t)`.

## Dupe — совпадение пары

| Поле | Тип | Правило |
|------|-----|---------|
| a, b | text | пути, `a < b` |
| kind | text | `exact` / `same` (пересжатие, разрешение, поля) / `trim` / `crop` |
| confidence | integer | 0–100 по правилу research R3 |
| offset_ms | integer | для `trim`: начало короткого в длинном |
| visual, audio, semantic | real | счета составляющих — для отладки и подбора порогов |

Группа — связные компоненты пар с `confidence ≥ 50` (ниже — не хранится). Лучшая копия — FR-009.

## DupeDismissed — «это разные видео»

| Поле | Тип |
|------|-----|
| a, b | text (пути, `a < b`), PK |

## Move (изменение)

| Поле | Тип | Правило |
|------|-----|---------|
| group_id | integer? | общий у ходов «Заменить»; `undo_last` забирает все ходы группы |

## Жизненный цикл

- Файл перемещён ходом — `path` отпечатка и пар обновляется в той же транзакции, что и ход.
- Файл исчез (уборка при запуске) — отпечаток и его пары удаляются.
