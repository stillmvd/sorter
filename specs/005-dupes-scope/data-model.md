# Data Model: Область поиска дублей

Схема таблиц не меняется. Новое — ключи `setting` и вычисляемый набор поиска.

## Настройка поиска дублей (`setting`)

| Ключ | Значения | По умолчанию | Кто пишет |
|------|----------|--------------|-----------|
| `dupes_enabled` | `1` / нет ключа | нет ключа = выключен | старт, настройки, «Включить поиск», Esc на шлюзе (возврат) |
| `dupes_scope` | `deck` / `all` | `deck` | старт, настройки, окно «Где искать дубли?» |
| `dupe_search` | JSON `SearchSpec` / нет ключа | нет ключа | `search_start`, `search_clear`, цикл разбора (`state`) |
| `dupes_rate_video_ms`, `dupes_rate_photo_ms` | целое | константы из замера R-6 | цикл разбора по концу этапа |

Правила:
- Общая на приложение (не на колоду); новая колода берёт текущее значение.
- `dupes_enabled` выключили → группы и плашки скрыты, отпечатки и пары остаются; включили снова — неизменённые файлы
  не читаются (сверка `size`+`mtime` в `fingerprint`).
- Во время раскладки: включение или расширение `deck → all` открывает шлюз разбора до конца этапа; Esc возвращает
  прежние `dupes_enabled` / `dupes_scope`. Сужение `all → deck` — сразу.

## Набор поиска (вычисляемый)

```text
Scope = Off | Deck | All | Search(SearchSpec)
```

| Набор | Файлы |
|-------|-------|
| `Off` | нет |
| `Deck` | карты колоды `in_deck`/`deferred`, существующие на диске |
| `All` | `Deck` + рекурсивно все стопки стола (`is_trash = 0`, `exists_on_disk = 1`) |
| `Search` | отмеченные стопки (рекурсивно) + колода, если `deck` + рекурсивно `folders`; без дублей путей |

- `Scope::current`: `dupe_search.state ∈ {running, done}` → `Search`, иначе по `dupes_enabled`/`dupes_scope`.
- Плашки на картах — всегда по набору колоды (`Deck`/`All`/`Off`), не по `Search`.
- Обход: скрытые/системные элементы и имена с `.`, `$`, `@` пропускаются; только `deck::media_name`.

## SearchSpec (JSON в `dupe_search`)

| Поле | Тип | Правило |
|------|-----|---------|
| `piles` | `string[]` | имена стопок текущего стола; пусто допустимо |
| `deck` | `bool` | колода по желанию |
| `folders` | `string[]` | абсолютные пути, добавляются системным диалогом по одному |
| `state` | `running` / `done` / `cancelled` | `running` — шлюз; `done` — итоги на экране «Дубли»; `cancelled` = ключ удаляется |
| `skipped` | `string[]` | недоступные папки (FR-021), показываются на панели и в плашке итогов |

Проверки при `search_start`: состав не пуст (хотя бы одна стопка, колода или папка); папка, вложенная в другую
папку состава, стопку стола или колоду, отбрасывается; совпадающие пути — один раз; одна папка — ищутся копии
внутри неё.

Переходы: нет ключа → `running` (`search_start`) → `done` (все файлы набора отпечатаны, точные копии посчитаны) →
нет ключа (`search_clear`: «Закрыть результаты» или новый поиск). `running` → нет ключа (Esc). Отпечатки снятых
файлов остаются при любом исходе (FR-020).

## Копия в группе (`GroupItem.where`)

| `where` | Подпись | Действия |
|---------|---------|----------|
| `deck` | «в колоде» | убрать копию, заменить |
| `pile` | «в стопке «Имя / подпапка»» | убрать копию, заменить (если лучшая в колоде) |
| `folder` | «в папке G:\vk videos» (полный путь каталога) | убрать копию; «заменить» — только если лучшая в колоде |

## Статус разбора (`develop::Status`)

- `stage`: `frames` → `dupes` (только если набор ≠ `Off`) → `hints` (если включены) → `done`; во время `Search`:
  `files` → `dupes` → `done` (кадры колоды не нужны).
- Новое поле `search: bool` — шлюз показывает заголовок «Ищу **дубли**», чип «Поиск дублей · …», кнопки «К дублям
  Enter» / «Отменить поиск Esc».
- Новое поле `scope: "off"|"deck"|"all"|"search"` — чип «Разбор колоды · дубли внутри колоды / в колоде и на столе».
- Удаляется `pair` (картинок на этапе «Дубли» больше нет).
