# Quickstart: проверка фичи 005

## Подготовка

- Стенд: `G:\sorter-test\big` (4 996 файлов), стол `G:\sorter-test\big-table` (Друзья 2, Мемы 1, Поездки 1),
  малая колода `G:\sorter-test\small-60`, внешняя папка `G:\vk videos` (там оригинал `1525005239349.mp4`,
  копии которого лежат в стопках).
- Для хода из внешней папки — копия: `G:\sorter-test\ext` (скопировать 3 файла из `G:\vk videos`, один из них —
  `1525005239349.mp4`). Оригинал `G:\vk videos` не трогать.
- Dev — команда из `CLAUDE.md` («Стенды»), отдельная база `SORTER_DATA=<scratchpad>\dev-005`; CDP 9225, приложение 1430.
- Проверки: `pnpm exec tsc --noEmit` → `pnpm build` → `cargo test --release --lib` (при запущенном dev —
  `CARGO_TARGET_DIR=target-test`).

## Сценарии

1. **Выключено по умолчанию (US1, SC-001)**: новая база → старт: шаг «Дубли» выключен, подпись «Выключено — колода
   откроется сразу после кадров.» → колода `big` → экран разбора: этапы «Файлы», «Кадры», чип «Разбор колоды»; по концу
   кадров — «Колода готова» не позже времени кадров + 10 с. На картах нет плашек; в журнале dev нет чтения стопок
   (`fingerprint` не растёт: `SELECT COUNT(*) FROM fingerprint` до и после).
2. **Внутри колоды / колода и стол (US2)**: `small-60` + `big-table`. Включить, «Внутри колоды» → разбор с этапом
   «Дубли», чип «· дубли внутри колоды» → группы только из колоды. Настройки → «Колода и стол» → шлюз → группа
   `1525005239349*` из стопок появляется. Снова «Внутри колоды» → группа со стопками исчезает сразу, без шлюза.
3. **Экран «Дубли» выключен (US3, SC-003)**: выключить поиск, Ctrl 3 → карточка «Поиск дублей **выключен**», нет слов
   «дублей нет». Enter → окно «Где искать дубли?» → Enter → шлюз; Esc на шлюзе → колода на той же карте, поиск снова
   выключен. Повтор до конца → «Раскладывать Enter» → та же карта, плашки на месте.
4. **Анимация (US4)**: на этапе «Дубли» живая область — сетка «Сито», без картинок и имён; Space — сетка замирает и
   гаснет; в Windows «Эффекты анимации» выкл. — неподвижный кадр.
5. **Отдельный поиск (US5, SC-004, SC-006)**: экран «Дубли» → F → панель: отметить Друзья и Мемы, «Добавить папку…»
   `G:\sorter-test\ext` и несуществующую `F:\нет` → «Сравню N файлов» = 2 + 1 + 3, `F:\нет` зачёркнута → Enter → шлюз
   «Ищу **дубли**», Esc отменяет (итогов нет, раскладка доступна). Повтор до конца → «К дублям Enter» → плашка
   «Отдельный поиск · N групп», копия `ext\1525005239349.mp4` — «в папке G:\sorter-test\ext». Убрать её → файл в корзине
   Windows, ход в журнале; Ctrl Z → файл снова в `ext` под тем же именем. «Закрыть результаты Esc» → группы колоды.
   Повтор того же состава — время ≤ 10 % первого.
6. **Скорость (US6, SC-005)**: замер до и после на `big` (свежая база): время этапа «Дубли» и время до 500 кадров с
   включённым и выключенным поиском; зонд подвисаний — максимум ответа окна < 1 с. Числа — в `research.md` R-6.
7. **Обе темы и узкое окно**: старт, «Дубли» (все состояния), панель «Найти дубли…», шлюз — в тёмной и светлой теме и
   при ширине окна 1100.
