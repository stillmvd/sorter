# Implementation Plan: Область поиска дублей

**Branch**: `005-dupes-scope` | **Date**: 2026-10-02 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/005-dupes-scope/spec.md`; форма экранов — выбор стендов 003/004/005
в `.planning/DESIGN.md`

## Summary

Поиск дублей управляется двумя общими настройками: `dupes_enabled` (по умолчанию выключен) и `dupes_scope`
(`deck` / `all`). Всё, что сейчас берёт `dupes::files()` (колода + все стопки), берёт **набор поиска** — одну функцию,
которая по настройкам отдаёт пусто / колоду / колоду и стопки, а во время отдельного поиска — его состав. От набора
зависят этап «Дубли» в `develop::status`, очередь отпечатков, точные копии, индекс кандидатов, группы на экране
«Дубли» и плашки на картах. Отдельный поиск — настройка `dupe_search` (JSON: стопки, колода, папки, `state`), цикл
разбора проходит её так же, как этап «Дубли»; итоги живут до «Закрыть результаты». Экран разбора на этапе «Дубли»
показывает анимацию «Сито» (CSS) вместо пар картинок. Скорость: сначала замер (FR-024), затем — список файлов один
раз на проход вместо `files()` на каждый файл, SHA-256 только после кадров и только в наборе, индекс только по
набору, снятие отпечатков в нескольких потоках.

## Technical Context

**Language/Version**: Rust (stable, edition 2021), TypeScript 5.8

**Primary Dependencies**: без новых крейтов: `rusqlite`, `serde_json` (уже есть), `windows` (MF), `ort` (DINOv2);
фронт — React 19, Tailwind 4, lucide, `@tauri-apps/plugin-dialog`

**Storage**: SQLite — новые ключи `setting`: `dupes_enabled`, `dupes_scope`, `dupe_search`; схема таблиц
`fingerprint`, `dupe`, `dupe_dismissed` без изменений

**Testing**: `cargo test --release --lib` — набор поиска по настройкам, состав отдельного поиска (вложенные папки,
недоступная папка, дубли путей), фильтр групп по набору, ход «убрать копию» из внешней папки и отмена, этапы статуса;
приёмка по [quickstart.md](quickstart.md) через CDP

**Target Platform**: Windows 11 x64

**Project Type**: desktop-app (Tauri 2)

**Performance Goals**: SC-005 — этап «Дубли» на `G:\sorter-test\big` ≤ ½ нынешнего, первые 500 кадров не медленнее,
чем с выключенным поиском; SC-006 — повтор отдельного поиска ≤ 10 % первого; окно не подвисает (зонд WM_NULL
`scratchpad/hangprobe.ps1` из десятой сессии)

**Constraints**: офлайн (III); файлы только перемещаются, «убрать копию» — ход в «Корзину» с журналом (I);
внешние папки не отслеживаются и не получают служебных файлов (III)

**Scale/Scope**: колода 5 000 файлов (2 053 видео, 2 943 фото), стол — единицы–тысячи файлов, внешняя папка — до
десятков тысяч; тест — `big`, `big-table`, `small-60`, `G:\vk videos`

## Constitution Check

| Принцип | Как соблюдён | Статус |
|---------|--------------|--------|
| I. Файлы в безопасности | копия во внешней папке убирается тем же `moves::trash_copies` → `move_with` (журнал до хода, между дисками — копия, сверка, удаление); Ctrl+Z возвращает в ту же папку под тем же именем — тест Rust до UI | ✅ |
| II. Одно решение — одно нажатие | ⚠ экран разбора держит раскладку, пока ищутся дубли (FR-008, FR-016) — см. Complexity Tracking; по умолчанию поиск выключен, и колода открывается сразу после кадров (US1) | ⚠ обосновано |
| III. Установщик, приватно | всё локально; во внешних папках ничего не пишется, отпечатки — в базе Sorter | ✅ |
| IV. Дизайн семейства | формы — стенды 003/004/005, выбор и числа — `.planning/DESIGN.md`, [contracts/ui.md](contracts/ui.md); анимация уважает `prefers-reduced-motion` | ✅ |
| V. Нативно и понятно | системный диалог выбора папки; «поиск выключен — разобрать дубли не получится» вместо «дублей нет»; у каждого действия клавиша | ✅ |
| VI. Простота кода | одна функция набора вместо трёх путей; отдельный поиск — JSON в настройке, без новых таблиц; анимация — CSS без библиотек | ✅ |

```text
src/
├── lib/ipc.ts
├── App.tsx            # шлюз: включение поиска и отдельный поиск открывают Develop с целью (deck / dupes / search)
└── components/
    ├── screens/{Start,Settings,Develop}.tsx, screens/DupesStep.tsx (новое — шаг «Дубли» для старта и настроек)
    ├── dupes/{DupesScreen,DupesOff,EnableDupes,FindDupes,SearchBanner}.tsx
    ├── fx/Sieve.tsx   # анимация «Сито»
    └── deck/DeckScreen.tsx  # строка «Ищу …», кнопка «Найти дубли… F», режим отдельного поиска
```

**Structure Decision**: тот же одиночный Tauri-проект; один новый модуль Rust (`dupes/search.rs`) — состав и обход
внешних папок, чтобы не раздувать `dupes/mod.rs`; новые компоненты по одному на выбранную форму.

## Порядок работ (для /speckit-tasks)

1. **Замер** (FR-024): bench-тест этапа «Дубли» на `big` с разбивкой — список файлов, SHA, декод отпечатка, DINOv2,
   сравнение; время до 500 кадров на свежей колоде. Итог — в [research.md](research.md) R-6.
2. Набор поиска + настройки (US1, US2): `scope_files`, статус без этапа «Дубли» при выключенном, фильтр групп и плашек,
   точные копии после кадров. Тесты Rust.
3. Старт и настройки: шаг «Дубли» (стенд 003) с оценкой времени.
4. Экран «Дубли» выключен + «Включить поиск» (стенд 004 B/A) и шлюз разбора с целью `dupes` (US3).
5. Анимация «Сито» и чип области на экране разбора (стенд 005, US4).
6. Отдельный поиск (US5): `dupes/search.rs`, команды, панель «Найти дубли…», плашка итогов, место «в папке …»,
   тест хода из внешней папки.
7. Скорость (US6) по итогам замера: список на проход, индекс по набору, параллельный съём; повторный замер.
8. Приёмка quickstart через CDP, обе темы, узкое окно.
