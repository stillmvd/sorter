# UI-контракт фичи 005

Формы и числа — выбор стендов в `.planning/DESIGN.md` (разделы «003 — выбор», «004 — выбор», «005 — выбор»),
разметка — `.planning/sketches/00{3,4,5}-*/stand.css` и `stand.js`. Здесь — где что живёт и как себя ведёт.

## Старт и настройки — шаг «Дубли» (стенд 003: Шаг A · Область B · Время B)

- Компонент `DupesStep` — четвёртый шаг стартового экрана под «Подсказками» и плитка в «Настройках» (тот же вид).
- Тумблер `dupes_enabled`; две строки области видны только при включённом; чип «+N мин» — из `dupes_estimate`,
  скрыт без колоды и при 0.
- Подписи: выключено — «Выключено — колода откроется сразу после кадров.»; «Внутри колоды» — «Сравню N файлов колоды
  между собой.»; «Колода и стол» — «Сравню N файлов колоды и M с K стопок стола.»; без колоды — «Сколько займёт — скажу,
  когда выберешь колоду.»
- В «Настройках» во время раскладки включение / расширение области → шлюз разбора с целью `dupes`.

## Экран «Дубли» (стенд 004)

| Состояние | Что видно |
|-----------|-----------|
| поиск выключен, итогов нет | заголовок «Дубли **не ищу**», чип «Поиск дублей выключен», карточка B: «Поиск дублей **выключен**», текст, «Включить поиск Enter», «Найти дубли… F», пояснение про отдельный поиск. Слов «дублей нет» нет |
| «Включить поиск» | окно A «Где искать **дубли?**», две области с числом файлов, «Займёт около N мин», «Отмена Esc», «Начать поиск Enter» → `dupes_enabled=1`, `dupes_scope`, шлюз `dupes` |
| поиск включён | строка под заголовком «Ищу **внутри колоды** · Изменить» (открывает то же окно A), в шапке «Найти дубли… F»; дальше — фильтры и группы как сейчас |
| «Найти дубли…» | панель B справа 430: стопки строками с флажками и «Все стопки», колода строкой, другие папки строками + «Добавить папку… Ctrl O» (системный диалог), недоступная — зачёркнута «нет доступа — пропущу»; низ «Сравню N файлов», «Отмена Esc», «Искать Enter» (неактивна при пустом составе) |
| итоги отдельного поиска | плашка A над фильтрами: «Отдельный поиск · N групп», состав и число файлов, пропущенные папки, «Новый поиск F», «Закрыть результаты Esc»; чип «Отдельный поиск»; группы — только этого поиска; копия во внешней папке — «в папке <каталог>» цветом `fg` |

Клавиши экрана «Дубли»: Enter — «Включить поиск» (в выключенном состоянии) / оставить выбранную копию (в группах, как
сейчас); F — «Найти дубли…»; Esc — закрыть окно / панель / итоги отдельного поиска; Ctrl O — «Добавить папку…» в панели.

## Экран разбора (стенд 005: Анимация A · Счёт A · Где ищу C)

- На этапе `dupes` живая область — `Sieve` (сетка 10×5, волна, три пары с дугами), подпись «СРАВНИВАЮ», без счёта и
  картинок. Пауза — замирает и гаснет до .5; «уменьшить движение» — неподвижный кадр.
- Чип: «Разбор колоды · дубли внутри колоды» / «… · дубли в колоде и на столе»; при выключенном поиске — «Разбор
  колоды», этапов «Файлы», «Кадры» (+ «Подсказки»).
- Цели шлюза (`App.tsx`):
  - `deck` — как сейчас (новая колода): «Раскладывать Enter», «Выбрать другую папку Esc».
  - `dupes` — включили поиск / расширили область во время раскладки: заголовок «Разбираю **колоду**», этап «Дубли»;
    по концу «Раскладывать Enter» → колода на той же карте; Esc — вернуть прежние настройки, в колоду.
  - `search` — отдельный поиск: заголовок «Ищу **дубли**», чип «Поиск дублей · <состав>», этапы «Файлы», «Дубли»,
    подпись «Итоги откроются, когда поиск закончится.», «К дублям Enter» (по концу), «Отменить поиск Esc» →
    `search_clear`, назад на экран «Дубли».
