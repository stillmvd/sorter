# Quickstart: приёмка фичи «Фото»

Подготовка: `python scripts/make-photo-set.py` → `G:\sorter-test\photos` (серии, дубли, поворот EXIF, без EXIF,
GIF, PNG с прозрачностью, битый файл). Dev-сервер с CDP — команда в `HANDOFF.md`. Проверки — через CDP.

1. **Карта фото** (SC-001): колода = копия `G:\vk photos` → 266 карт; фото с EXIF-поворотом стоит прямо; сведения:
   дата, камера, разрешение, размер; у файла без EXIF — «Дата из имени» / «Дата файла»; GIF играет; битый файл —
   карта с текстом ошибки, раскладывается клавишей.
2. **Ход и отмена**: клавиша стопки → файл в стопке, Ctrl+Z → на месте под прежним именем; Del → корзина Windows.
3. **Фильтр** (US2): смешанная колода (`G:\vk videos` + фото) → «Фото» — только фото, счётчики сходятся;
   перезапуск — фильтр тот же; «Видео» до конца → предложение переключиться на фото.
4. **Стопки**: на плитке стопки значки видео и фото со своими числами.
5. **Серия** (US3, SC-003, SC-004): на наборе серии собраны одной картой; отметить 2 из 5, клавиша стопки → 2 в
   стопке, 3 в корзине, в журнале один ход; Ctrl+Z → все 5 в колоде; «оставить в колоде» → 3 остаются картами;
   «Разбить серию» S → 5 отдельных карт; без отметок → вся серия в стопку.
6. **Стол**: серия — одна плитка «Серия · N», ход кладёт всю серию; «Отмечено K · F файлов».
7. **Подсказки** (SC-006): 10 похожих фото в одну стопку → следующее похожее просится туда.
8. **Дубли** (SC-005): уменьшенная, пережатая, кадрированная копии находят оригинал; снимки одной серии не
   дубли друг другу; на `G:\vk photos` ≤ 1 ложной плашки.
9. **Скорость** (SC-002): 50 переходов по картам фото — p95 ≤ 100 мс (замер скриптом CDP, как `%TEMP%\sc002.js`).
10. **Только видео** (SC-007): колода `G:\vk videos` — клавиши, ходы и скорость как до фичи.
