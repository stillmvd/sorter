# Feature Specification: Главный экран и разбор нескольких папок

**Feature Branch**: `007-home-screen`

**Created**: 2026-11-18

**Status**: Draft

**Input**: User description: "У приложения нет как такового главного экрана. Захожу в приложение — хочу видеть главную страничку с плитками «Папка для разбора» и «Папка, куда раскладывать», и чтобы я мог перетаскиванием из Проводника на эти плитки выбирать папку. На главном экране — если какой-то разбор не закончен, что-то вроде «Продолжить разбор». Реализовать выбор нескольких папок с медиа для разбора: например, в Downloads\2ch медиа лежат по папкам тредов, я хочу их все разобрать по папкам в E:\Backup\randomtube, где уже собраны коллекции."

## Clarifications

### Session 2026-11-18 (до спеки)

- Q: Как разбирать несколько папок? → A: Одна колода из всех выбранных папок, вложенные папки берутся тоже. На карте
  видно, из какой папки файл.
- Q: На какую глубину брать вложенные? → A: Все уровни. Папка стола, если она внутри, пропускается.
- Q: Что показывать в «Продолжить разбор»? → A: Список незаконченных разборов: папки, стол, «осталось 340 из 900»,
  когда открывал. Нажал — продолжаешь с того же места.
- Q: Что открывается при запуске? → A: Всегда главный экран. Enter продолжает последний разбор.
- Q: Что делает «Разобрать с Sorter» в Проводнике? → A: Открывает главный экран, папка уже лежит в плитке «Папка для
  разбора»; видно стол, можно добавить ещё папки.
- Q: Что делать с опустевшими папками-источниками после разбора? → A: Предложить убрать: на экране «Колода
  разобрана» действие «Убрать N пустых папок» — в корзину Windows, с отменой.
- Q: Как работает отмена, когда разборов несколько? → A: В рамках разбора: Ctrl Z и «Последний ход» — только ходы
  открытого разбора. Журнал показывает все ходы с пометкой разбора, чужой ход там можно забрать вручную.

### Находки `/scenarios` (2026-11-18), учтённые в требованиях

- Пропавшая папка сейчас закрывает всё приложение стартовым экраном — журнал и отмена недоступны (ТУПИК 9–11).
- Запуск из Проводника молча меняет колоду посреди разбора (ВРЕД 1).
- Одна папка разными строками (`C:\X` и `c:\x`, junction, подстановка диска) — две колоды (ВРЕД 6, m1).
- Числа: «N видео» на старте считает и фото; счётчик не обновляется, когда в папку приходят файлы (ПУТАНИЦА 16–17).
- Папка, где видео только во вложенных (`Downloads\2ch`), даёт «0 видео» и пустую колоду (ТУПИК 14).
- Чтение папки видно только на стартовом экране; из Проводника и настроек — тишина (27).

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Перетащил папку на плитку — разбор готов (Priority: P1)

Пользователь запускает Sorter и видит главный экран с двумя плитками: «Папка для разбора» и «Папка, куда
раскладывать». Он тащит `Downloads\2ch` из Проводника на первую плитку, `E:\Backup\randomtube` — на вторую. Плитки
показывают, что внутри: «2ch — 14 папок, 1 236 видео, 310 фото» и «randomtube — 23 стопки». Действие «Разобрать»
открывает разбор.

**Why this priority**: это основной вход в приложение; без него нет ни нескольких папок, ни продолжения.

**Independent Test**: с пустой базой перетащить папку на каждую плитку и начать разбор; то же — через кнопку выбора.

**Acceptance Scenarios**:

1. **Given** главный экран без выбранных папок, **When** пользователь перетаскивает папку из Проводника на плитку
   «Папка для разбора», **Then** папка добавляется в плитку и показывается счётчик найденных файлов по ходу чтения.
2. **Given** пользователь тащит папку над окном, **When** курсор над плиткой, **Then** плитка подсвечивается как цель;
   отпущенное мимо плиток ничего не меняет.
3. **Given** перетаскивают файл, а не папку, **When** его отпускают на плитку, **Then** плитка объясняет, что нужна
   папка, ничего не меняется.
4. **Given** в плитке «Папка, куда раскладывать» уже есть папка, **When** на неё перетаскивают другую, **Then** стол
   заменяется (стол всегда один).
5. **Given** обе плитки заполнены, **When** пользователь нажимает «Разобрать» (Enter), **Then** открывается разбор.

### User Story 2 - Несколько папок и вложенные — одной колодой (Priority: P1)

Пользователь кладёт в плитку «Папка для разбора» `Downloads\2ch` (внутри папки тредов) и ещё `Downloads\vk`. Все
медиа из обеих папок и всех вложенных становятся одной колодой. На карте видно, из какой папки файл
(«2ch › тред 312»). Пользователь раскладывает их по стопкам `randomtube`.

**Why this priority**: прямая просьба владельца; без неё папки тредов приходится выбирать по одной.

**Independent Test**: папка с 3 вложенными папками по 10 файлов + отдельная папка с 5 файлами → колода из 35 карт.

**Acceptance Scenarios**:

1. **Given** папка с вложенными папками, **When** её кладут в плитку, **Then** в колоду попадают медиа всех уровней
   вложенности, плитка пишет, сколько папок и файлов найдено.
2. **Given** в плитке уже есть папка, **When** на неё перетаскивают ещё одну, **Then** папка добавляется к списку, а не
   заменяет его; любую папку из списка можно убрать.
3. **Given** папка стола лежит внутри папки для разбора, **When** папки выбраны, **Then** стол и всё внутри него в
   колоду не попадает, и плитка об этом говорит.
4. **Given** одна выбранная папка лежит внутри другой выбранной, **When** их добавляют, **Then** файлы не
   дублируются — вложенная папка поглощается внешней.
5. **Given** в разбираемой папке появились новые файлы в любой вложенной папке, **When** разбор открыт, **Then** они
   приходят в колоду, как сейчас приходят файлы верхнего уровня.

### User Story 3 - Продолжить брошенный разбор (Priority: P1)

Пользователь разложил 560 из 900 файлов `2ch` и закрыл Sorter. Через три дня запускает его: на главном экране блок
«Продолжить разбор» с плиткой «2ch, vk → randomtube · осталось 340 из 900 · 15 ноября». Нажал (или Enter) —
открывается колода с того же места, без повторной проявки.

**Why this priority**: владелец разбирает урывками; сейчас вернуться к разбору можно только повторным выбором
папки.

**Independent Test**: начать разбор, разложить часть, начать другой, вернуться на главный экран — видны оба
разбора с верными остатками, каждый продолжается с места.

**Acceptance Scenarios**:

1. **Given** есть незаконченные разборы, **When** открыт главный экран, **Then** каждый показан плиткой с папками,
   столом, остатком и датой последнего открытия; последний — первым.
2. **Given** пользователь продолжает разбор, **When** колода открывается, **Then** уже проявленные карты не
   проявляются заново (фича 006), стол — тот, с которым разбор начинался.
3. **Given** разбор закончен (в колоде 0 карт), **When** открыт главный экран, **Then** этого разбора в списке нет.
4. **Given** пользователь больше не хочет продолжать разбор, **When** он убирает его из списка, **Then** разбор
   исчезает, файлы и уже сделанные ходы не трогаются, ходы остаются в журнале.
5. **Given** одна из папок разбора пропала (диск отключён), **When** открыт главный экран, **Then** плитка разбора
   показывает «Папки нет — подключи диск» и не блокирует остальное приложение; когда папка вернулась, плитка
   оживает сама, без перезапуска.

### User Story 4 - «Разобрать с Sorter» из Проводника (Priority: P2)

Пользователь щёлкает правой кнопкой по папке в Проводнике → «Разобрать с Sorter». Sorter (запущенный или нет)
показывает главный экран, папка уже лежит в плитке «Папка для разбора», стол подставлен последний. Если в этот момент
открыт другой разбор, он не теряется — остаётся в «Продолжить разбор».

**Why this priority**: вход уже есть (фича 003), но сейчас молча меняет колоду посреди разбора.

**Independent Test**: открыть разбор A, из Проводника выбрать папку B → главный экран с B в плитке, A в списке
«Продолжить».

**Acceptance Scenarios**:

1. **Given** Sorter закрыт, **When** выбран пункт меню Проводника, **Then** открывается главный экран с этой папкой в
   плитке.
2. **Given** Sorter открыт на разборе A, **When** из Проводника приходит папка B, **Then** окно выходит на передний
   план с главным экраном, B в плитке, A — в «Продолжить разбор».
3. **Given** выбранная из Проводника папка уже входит в незаконченный разбор, **When** она приходит, **Then** главный
   экран предлагает продолжить этот разбор, а не начинать новый.

---

### User Story 5 - Разобрал — убрать пустые папки (Priority: P3)

Колода `2ch` разобрана, папки тредов опустели. На экране «Колода разобрана» есть действие «Убрать 14 пустых папок».
Они уходят в корзину Windows одним ходом; Ctrl Z возвращает.

**Why this priority**: приятное завершение, без него пользователь чистит папки руками.

**Independent Test**: разобрать папку с вложенными до конца → действие с верным числом → папки в корзине → Ctrl Z
возвращает.

**Acceptance Scenarios**:

1. **Given** колода разобрана и среди папок-источников есть пустые, **When** открыт экран «Колода разобрана»,
   **Then** видно действие с числом пустых папок.
2. **Given** в папке остались не-медиа файлы (`.txt`, `.html`), **When** считаются пустые папки, **Then** такая
   папка пустой не считается и не убирается.
3. **Given** пустые папки убраны, **When** пользователь нажимает Ctrl Z, **Then** папки возвращаются на место.

### Edge Cases

- Одна и та же папка, записанная разными строками (регистр, слэши, junction, подстановка диска) — одна папка.
- Перетащили на плитку сразу несколько папок — добавляются все.
- Перетащили папку, в которой нет медиа ни на одном уровне — плитка говорит «Здесь нет видео и фото», в список не
  добавляет.
- Выбрали стол внутри папки для разбора — стол исключается из колоды, но не запрещается.
- Выбрали папку для разбора внутри стола или совпадающую со столом — отказ с объяснением, какая папка конфликтует.
- Очень глубокая или огромная вложенность (тысячи папок) — чтение показывает прогресс и не вешает окно; его можно
  отменить.
- Папка-источник пропала посреди разбора — её карты недоступны, остальные карты колоды раскладываются дальше.
- Закрыли окно во время чтения папок — при следующем запуске ничего не сломано, выбор можно повторить.
- Две колоды с общей папкой — добавление папки, которая уже в другом незаконченном разборе, предлагает
  продолжить его.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: При каждом запуске открывается главный экран: плитки «Папка для разбора», «Папка, куда раскладывать»,
  блок «Продолжить разбор» (если есть незаконченные) и действие «Разобрать».
- **FR-002**: Папку можно выбрать перетаскиванием из Проводника на плитку и кнопкой выбора; оба пути дают один
  результат. На плитку «Папка для разбора» можно перетащить несколько папок сразу.
- **FR-003**: Плитка «Папка для разбора» хранит список папок; каждую можно убрать. Плитка «Папка, куда
  раскладывать» хранит одну папку.
- **FR-004**: Колода — все медиа из всех папок списка на всех уровнях вложенности, без папки стола и без повторов.
- **FR-005**: Плитки показывают живые и одинаковые с остальными экранами числа: сколько папок, видео и фото найдено
  (отдельно), сколько стопок на столе. Пока папки читаются — счётчик растёт, чтение можно отменить.
- **FR-006**: Карта показывает, из какой папки файл, относительно выбранной папки («2ch › тред 312»).
- **FR-007**: Разбор (набор папок + стол) запоминается; незаконченные разборы показываются в «Продолжить разбор» с
  остатком и датой; Enter продолжает последний.
- **FR-008**: Разбор можно убрать из списка без последствий для файлов и журнала.
- **FR-009**: Пропавшая папка помечается только на своей плитке или в своём разборе; остальное приложение (другие
  разборы, журнал, отмена, настройки) работает. Возвращение папки замечается без перезапуска (при возврате фокуса
  окна и по действию «Проверить снова»).
- **FR-010**: «Разобрать с Sorter» из Проводника кладёт папку в плитку главного экрана; открытый разбор не теряется.
- **FR-011**: Ctrl Z и «Последний ход» работают в рамках открытого разбора. Журнал показывает ходы всех разборов с
  пометкой, из какого он; ход другого разбора можно забрать из журнала вручную.
- **FR-012**: Папка, записанная разными способами, распознаётся как одна и та же — для колоды, стола и проверки
  вложенности.
- **FR-013**: По окончании разбора экран «Колода разобрана» предлагает убрать опустевшие папки-источники одним ходом
  в корзину Windows с записью в журнал и отменой; папки с любыми оставшимися файлами не трогаются, сами выбранные
  корневые папки — тоже (только вложенные).
- **FR-014**: Переключатели «Подсказки» и «Дубли» переезжают с текущего стартового экрана в настройки и на главный
  экран в той форме, которую утвердит стенд; их значения не меняются при выборе папок.

### Key Entities

- **Разбор**: набор папок-источников, стол, дата начала и последнего открытия, остаток карт. Незаконченный —
  пока в колоде есть карты.
- **Папка-источник**: корневая папка, выбранная пользователем; её вложенные папки входят в колоду.
- **Стол**: папка со стопками, одна на разбор.
- **Карта**: файл колоды; знает свою папку-источник и путь относительно неё.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: От запуска до начала разбора двух новых папок перетаскиванием — не больше 3 действий пользователя
  (перетащить, перетащить, «Разобрать»).
- **SC-002**: Возврат к брошенному разбору — одно действие с главного экрана (клик или Enter).
- **SC-003**: Папка `Downloads\2ch` с папками тредов разбирается одной колодой без выбора каждой вложенной папки.
- **SC-004**: Числа видео, фото и остатка совпадают на главном экране, в разборе и на экране «Колода разобрана».
- **SC-005**: Отключение диска с одной папкой не закрывает доступ к журналу, отмене и другим разборам.

## Assumptions

- Фича 006 (проявленное хранится) делается раньше: без неё «Продолжить разбор» снова проявлял бы всё.
- Форма главного экрана — по стенду 009 (`.planning/sketches/009-home-screen/stand.template.html`, выбор
  2026-11-18): компоновка A — плитки сверху, кнопка «Разобрать» под ними, «Продолжить разбор» внизу экрана;
  плитки A — строки папок (имя, путь, «41 папка · 802 видео · 231 фото», убрать), итог «1 220 карт» в шапке плитки;
  перетаскивание A — плитка в рамке с подписью «Отпусти — добавлю 2 папки»; «Продолжить разбор» C — последний
  разбор крупно с кадром следующей карты и «Продолжить Enter», остальные строками; «Подсказки» и «Дубли» B —
  строками с переключателями в плитке стола; папка на карте A — строкой над именем файла в колонке сведений.
- Перетаскивание из Проводника включается для окна целиком; внутренние перетаскивания карт на стопки работают как
  раньше (проверить при планировании).
- Стол на разбор один; разные разборы могут иметь разные столы.
- Разборы, начатые до этой фичи (одна папка без вложенных), становятся разборами из одной папки; их колода при
  следующем открытии начинает брать и вложенные папки — плитка предупреждает, сколько добавится.
