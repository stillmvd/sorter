# Quickstart: проверка главного экрана

Dev: `SORTER_DATA=<временная папка>`, CDP 9225 (`HANDOFF.md`). Данные: `G:\sorter-test\big`, `G:\sorter-test\vid-30`,
стол `G:\sorter-test\big-table`, копия с вложенными папками `G:\sorter-test\nested` (3 папки по 10 файлов + 5 в корне).

1. **Первый запуск**: пустая база → главный экран, обе плитки пустые, «Разобрать» выключена, подпись «Сначала выбери
   папки».
2. **Перетаскивание**: `add_roots(["G:\sorter-test\nested"])` (CDP; перетаскивание мышью — вручную) → строка
   «nested — 3 папки · 35 видео», итог «35 карт». Файл вместо папки → строка ошибки в плитке, ничего не добавлено.
3. **Несколько папок**: добавить `vid-30` → итог `35 + 18`; добавить `nested\a` → «Уже входит в «nested»».
4. **Стол внутри**: стол `nested\stol` → его файлы не в колоде.
5. **Разобрать**: Enter → колода, у карты из `nested\a` строка «nested › a». Разложить 3 карты, Ctrl Z — отмена
   последнего хода этого разбора.
6. **Продолжить**: вернуться на главный экран → разбор крупно «осталось 50 из 53» с кадром, Enter — колода с того же
   места, без экрана проявки.
7. **Два разбора**: собрать второй из `big`, вернуться → оба в «Продолжить», последний первым; убрать один — файлы и
   журнал на месте.
8. **Пропавшая папка**: переименовать корень на диске → плитка «Папки нет…», журнал и настройки открываются;
   вернуть имя, «Проверить снова» → плитка ожила.
9. **Проводник**: `sorter.exe G:\sorter-test\vid-30` при открытом разборе → главный экран, папка в плитке (или
   «уже в разборе» с «Продолжить»), открытый разбор в списке.
10. **Пустые папки**: разобрать `nested` до конца → «Убрать 3 пустые папки» → в корзине, Ctrl Z возвращает.
11. **Старая база**: копия базы 1.6.0 → разбор из прежней колоды в «Продолжить», ходы в журнале с его подписью.
