# Research: Главный экран и разбор нескольких папок

## R1. Разбор — таблицы `review` и `review_root`, карта остаётся при корне

- **Решение**: `review(id, table_path, started, created_at, opened_at)` и `review_root(review_id, path, ord)` с
  `UNIQUE(path)`: папка-корень принадлежит одному разбору. Открытый разбор — `settings.review_id`. Карта по-прежнему
  хранит `deck_path` = корень, а `file_name` — путь от корня (`тред 312\a.mp4`). Представление
  `open_root(path)` — корни открытого разбора; запросы колоды вместо `deck_path = ?` берут
  `deck_path IN (SELECT path FROM open_root)`.
- **Почему**: все склейки `Path::new(deck_path).join(file_name)` (ход, проявка, подсказки, дубли, плеер) продолжают
  работать без правок, уникальный индекс `card_in_deck(deck_path, file_name NOCASE)` защищает от повторов, проявленное
  из фичи 006 живёт при корне и переживает любые разборы.
- **Отвергнуто**: `deck_path` = ключ разбора и абсолютный путь в `file_name` — ломает все склейки и дублирует карты
  при общей папке у двух разборов.

## R2. Черновик главного экрана — разбор с `started = 0`

- **Решение**: плитки главного экрана — это черновик: единственная строка `review` с `started = 0`. Добавить папку —
  вставить `review_root` черновика и сразу сверить корень (карты появляются в базе, числа на плитке берутся из базы).
  «Разобрать» — `started = 1`, `opened_at = now`, `settings.review_id = id`, новый пустой черновик со столом
  последнего разбора.
- **Почему**: числа на плитке, в разборе и на «Колода разобрана» считаются одним запросом (SC-004); «Разобрать»
  мгновенный — сверка уже прошла.
- **Отвергнуто**: отдельный подсчёт без вставки карт — двойное чтение папок и расхождение чисел.

## R3. Папка уже в другом разборе

- **Решение**: `add_root` черновика: если папка — корень незаконченного разбора, ответ `IN_REVIEW` с id разбора;
  плитка показывает строку ошибки «Эта папка уже в разборе «2ch → randomtube»» и кнопку «Продолжить». Если разбор
  закончен (в колоде 0 карт) — корень переходит в черновик, пустой старый разбор удаляется.
- **Почему**: требование «добавление папки из другого разбора предлагает продолжить его» без второй колоды на тех же
  файлах.

## R4. Вложенность: обход всех уровней, стол пропускается, вложенные корни поглощаются

- **Решение**: свой обход в глубину по `fs::read_dir` (без новых зависимостей): каталоги-ссылки (junction, symlink) не
  обходятся, пропускаются папка стола, `$RECYCLE.BIN`, `System Volume Information` и скрытые системные. Обход сообщает
  число найденных файлов (`deck://reading`) и прерывается флагом `AppState.stop_reading`.
- Новый корень внутри имеющегося — не добавляется, плитка говорит «Уже входит в «2ch»». Имеющийся корень внутри
  нового — его карты переписываются на новый корень (`deck_path = new`, `file_name = rel\name`) одним `UPDATE`, его
  строка `review_root` удаляется. Корень внутри стола или равный столу — отказ `INSIDE_TABLE`.

## R5. Одна папка — одна строка (FR-012)

- **Решение**: `paths::canon(p)` = `fs::canonicalize` без префикса `\\?\` (`\\?\UNC\` → `\\`) и без хвостового
  разделителя; недоступный путь — нормализация строки (слэши, хвост). Канонизируются корни, стол и аргумент
  Проводника. Миграция переписывает существующие `card.deck_path` и `pile.table_path` в каноническую форму, если
  папка доступна и форма отличается.

## R6. Ход из вложенной папки

- **Решение**: в стопку кладётся имя файла (`Path::file_name`), не путь от корня: `free_name(&dir, basename, …)`.
  Отмена возвращает по `from_path`, вложенная папка-источник должна существовать — если её убрали, отмена создаёт её
  заново (`create_dir_all(parent)`).

## R7. Отмена в рамках разбора (FR-011)

- **Решение**: `move.review_id` (новая колонка, старые ходы — разбор из миграции). `undo_last`/`undo_since` берут
  только ходы открытого разбора; журнал отдаёт подпись разбора («2ch → randomtube»), ход другого разбора забирается
  кнопкой в журнале как сейчас.

## R8. Пропавшая папка не закрывает приложение (FR-009)

- **Решение**: `state.missing` больше не уводит на стартовый экран. `review_root.online` обновляется watcher'ом
  (`is_dir` каждые 2 с, дёшево) и командой `recheck`. Колода показывает карты только доступных корней
  (`open_root` с `online = 1`), плитка корня и разбора — «Папки нет — подключи диск G:» и «Проверить снова». Стол
  пропал — плитка стола и прежнее сообщение на колоде; журнал и отмена доступны.

## R9. Watcher

- **Решение**: корни открытого разбора — `RecursiveMode::Recursive`, стол — как сейчас. После любого события —
  `deck::sync` по каждому доступному корню. Черновик не наблюдается: плитка пересверяется при фокусе окна.

## R10. «Разобрать с Sorter» (FR-010)

- **Решение**: `folder_arg` больше не вызывает `choose_deck`: папка добавляется в черновик (`add_root`), фронт получает
  `home://incoming` и показывает главный экран. Открытый разбор остаётся в «Продолжить». Конфликт с разбором — как в
  R3.

## R11. Пустые папки (FR-013)

- **Решение**: `empty_dirs(review)` — вложенные (не корни) папки, где не осталось ни одного файла на любом уровне;
  в ответ идут только верхние такие папки. «Убрать N пустых папок» — ход в стопку «Корзина» с путями каталогов
  (`moves::place` с `paths`, для корзины разрешены каталоги), отмена — восстановление из корзины Windows.

## R12. Форма — стенд 009

- Компоновка A, плитки A, перетаскивание A (рамка на плитке под курсором: «Отпусти — добавлю N папок» / для стола
  «Отпусти — раскладывать сюда»), «Продолжить» C (последний крупно с первым кадром следующей карты), переключатели B
  (строками в плитке стола), папка на карте A (строкой над именем файла). Ошибки (файл вместо папки, нет медиа,
  внутри стола, уже в разборе) — строкой `l2 err` в своей плитке, как «Папки нет» на стенде.
- Перетаскивание из Проводника: `dragDropEnabled: true`, `getCurrentWebview().onDragDropEvent`; цель — плитка под
  `position / devicePixelRatio` через `elementFromPoint`. Внутренние перетаскивания построены на pointer-событиях —
  включение не мешает им.

## R13. Порядок карт в разборе

- **Решение**: новая карта получает позицию после максимума по всем корням своего разбора — папки идут в колоде
  друг за другом, внутри папки — по пути от корня (вложенные папки подряд).
