# Feature Specification: Установщик и обновления

**Feature Branch**: `003-installer-updates`

**Created**: 2026-09-29

**Status**: Draft

**Input**: User description: "Фича 003 «Установщик и обновления». Sorter перестаёт быть portable: полноценный NSIS-установщик как в других приложениях пользователя (образцы: Markdown — updater installMode quiet; Booked — GitHub Releases с latest.json; Echo Studio — свой шаблон nsis/installer.nsi). Релизы публикуются в GitHub Releases, приложение тихо проверяет и ставит обновления. В настройках — блок «Версия и обновления» (нарисован на кадре HSettings холста, твик update; сейчас на его месте TODO в Settings.tsx). Пункт контекстного меню Проводника «Разобрать с Sorter» на папке: открывает окно с этой папкой как колодой, стол можно выбрать другой. Первый запуск остаётся с двумя папками, но с понятными подписями («Откуда брать видео» / «Куда раскладывать»). Первый релиз (бывший T053 фичи 001) выходит сразу установщиком. Принцип III конституции (один exe без установщика, без сети) нужно пересмотреть: единственная сеть — проверка обновлений на GitHub."

## Clarifications

### Session 2026-09-29

- Q: Где виден пункт «Разобрать с Sorter» в Windows 11? → A: Классический пункт меню папки; в Windows 11 — под
  «Показать дополнительные параметры» (и по Shift + правый клик). Основное меню Windows 11 не делаем.
- Q: Sorter уже открыт с другой колодой — что делает пункт Проводника? → A: Одно окно: оно выходит вперёд
  и переключается на новую колоду; прежняя колода просто заменяется, её можно выбрать снова.
- Q: Где релизы? → A: Публичный репозиторий `stillmvd/sorter` на GitHub, релизы оттуда.
- Q: Куда ставить — для всех пользователей или только для себя? → A: Для всех, как Markdown / Booked / Echo Studio;
  установка обновления просит подтверждения администратора Windows (UAC) — это единственное окно обновления.
- Q: Пункт Проводника на фоне открытой папки тоже? → A: Да: и на значке папки, и по правому клику на пустом месте
  внутри папки.
- Q: Показывать ли «Что нового»? → A: Да, в блоке «Версия и обновления»: описание готового к установке или последнего
  поставленного обновления. Раскладку ничто не перебивает.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Установка как у остальных приложений (Priority: P1)

Пользователь скачивает со страницы релиза один файл установщика, запускает его и проходит установку на русском:
Sorter появляется в меню «Пуск», на рабочем столе (по желанию) и в «Приложениях» Windows со своим знаком, версией
и издателем. Удаление — штатно через «Приложения»; разложенные видео, стопки и данные Sorter при этом не трогаются,
пока пользователь сам не попросит удалить данные.

**Why this priority**: без установщика нет ни обновлений, ни пункта в Проводнике; это первый релиз (бывший T053).

**Independent Test**: на чистой учётной записи запустить установщик, открыть Sorter из «Пуска», разложить карту,
удалить через «Приложения» — видео на своих местах, повторная установка подхватывает прежние колоду, стол и журнал.

**Acceptance Scenarios**:

1. **Given** Sorter не установлен, **When** пользователь запускает установщик и соглашается с шагами,
   **Then** Sorter установлен, есть ярлык в «Пуске», приложение запускается со знаком Sorter.
2. **Given** Sorter установлен и работал, **When** пользователь удаляет его через «Приложения»,
   **Then** программа и пункт Проводника исчезают, файлы в колоде и стопках не тронуты.
3. **Given** Sorter удалён без удаления данных, **When** его ставят снова, **Then** колода, стол, клавиши стопок,
   журнал и подсказки на месте.
4. **Given** на компьютере нет нужного компонента для показа окна, **When** идёт установка,
   **Then** установщик ставит его сам и говорит об этом по-русски.

### User Story 2 - Тихие обновления (Priority: P1)

Sorter сам узнаёт о новой версии, скачивает её в фоне и ставит так, чтобы не мешать раскладке: не перезапускается
посреди работы и не теряет ни одного хода. В настройках, в блоке «Версия и обновления», видно текущую версию,
состояние («последняя версия», «скачивается 1.2.0», «готово — перезапусти, чтобы обновить», «не удалось проверить —
нет сети») и кнопка «Проверить сейчас». Проверку можно выключить.

**Why this priority**: пользователь не должен вручную следить за релизами; обновления — главный смысл установщика.

**Independent Test**: поставить версию N, выложить N+1, запустить Sorter — через минуту блок показывает готовое
обновление, после перезапуска версия N+1, журнал и настройки на месте.

**Acceptance Scenarios**:

1. **Given** есть новая версия, **When** Sorter запущен, **Then** он скачивает её в фоне без окон и звуков,
   а в настройках появляется «Готово — перезапусти, чтобы обновить» с кнопкой «Перезапустить».
2. **Given** обновление скачано, **When** пользователь закрывает Sorter, **Then** Windows один раз просит
   разрешение администратора, обновление ставится без других окон, и следующий запуск уже новой версией.
7. **Given** пользователь отказал в разрешении администратора, **When** Sorter снова запущен, **Then** работает
   прежняя версия, в блоке — «Обновление не поставлено — нужно разрешение Windows» и кнопка «Перезапустить».
3. **Given** идёт ход (файл перемещается), **When** пользователь жмёт «Перезапустить», **Then** Sorter сперва
   дописывает ход, потом ставит обновление.
4. **Given** нет сети, **When** Sorter проверяет обновления, **Then** раскладка работает как обычно, в блоке —
   «Не удалось проверить — нет сети. Попробую позже», никаких всплывающих ошибок.
5. **Given** пользователь выключил проверку обновлений, **When** Sorter работает, **Then** он не делает ни одного
   сетевого запроса.
6. **Given** скачанный файл обновления повреждён или подписан не тем ключом, **When** Sorter пытается его поставить,
   **Then** обновление отклоняется, текущая версия работает, в блоке — причина и «Попробую позже».

### User Story 3 - «Разобрать с Sorter» из Проводника (Priority: P2)

Пользователь в Проводнике щёлкает правой кнопкой по папке с видео и выбирает «Разобрать с Sorter». Открывается
Sorter, где эта папка — колода. Стол — прежний; если пользователь хочет раскладывать в другое место, он меняет стол
прямо в окне, не заходя в настройки.

**Why this priority**: быстрый вход для новой папки, но раскладка работает и без него.

**Independent Test**: правый клик по папке → «Разобрать с Sorter» → окно с этой папкой в шапке и её видео
в колоде; смена стола из этого окна — карты ложатся в новый стол.

**Acceptance Scenarios**:

1. **Given** Sorter установлен и стол уже выбран, **When** пользователь выбирает «Разобрать с Sorter» на папке,
   **Then** Sorter открывается с этой папкой как колодой и прежним столом.
2. **Given** Sorter уже открыт с другой колодой, **When** пользователь выбирает пункт на новой папке,
   **Then** второе окно не открывается: открытое выходит вперёд и переключается на новую колоду (если идёт ход —
   после его завершения).
3. **Given** папка — это сам стол или лежит внутри стола, **When** пользователь выбирает пункт, **Then** Sorter
   объясняет, что колода не может лежать в столе, и предлагает выбрать другой стол.
4. **Given** стол ещё не выбран (первый запуск), **When** пользователь выбирает пункт, **Then** открывается первый
   запуск с уже заполненной колодой, остаётся выбрать, куда раскладывать.
5. **Given** пункт вызван на папке без видео, **When** Sorter открывается, **Then** он показывает пустую колоду
   с объяснением, что видео в папке нет.

---

### User Story 4 - Понятный первый запуск (Priority: P3)

Первый запуск остаётся с двумя папками, но подписи отвечают на вопрос пользователя: «Откуда брать видео» и
«Куда раскладывать» — с одной строкой пояснения под каждой.

**Why this priority**: косметика, но первый экран видит каждый новый пользователь.

**Independent Test**: сбросить настройки, запустить Sorter — видны обе подписи и пояснения, выбор папок работает
как раньше.

**Acceptance Scenarios**:

1. **Given** первый запуск, **When** открылось окно, **Then** две плитки: «Откуда брать видео» и
   «Куда раскладывать», у каждой строка пояснения и кнопка выбора папки.

### Edge Cases

- Проверка обновлений во время раскладки медленной сетью — раскладка не тормозит, смена карты по-прежнему
  укладывается в SC-002 фичи 001.
- Пользователь закрыл Sorter посреди скачивания — при следующем запуске скачивание начинается заново или
  докачивается; частичный файл не ставится.
- Обновление не поставилось (нет прав, файл занят) — остаётся текущая версия, в блоке — причина и что сделать.
- Выложена версия старше установленной — Sorter её не ставит.
- Путь папки с кириллицей, пробелами, на сетевом или съёмном диске — пункт Проводника передаёт его целиком.
- Пункт вызван на нескольких выделенных папках — берётся первая, остальные не открываются.
- Установка поверх прежней portable-копии: данные в `%APPDATA%\com.stillmvd.sorter` подхватываются как есть.
- Переустановка поверх той же версии (починка) — данные не трогаются.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Sorter MUST распространяться одним файлом установщика на русском языке со знаком Sorter, версией
  и издателем.
- **FR-002**: Установщик MUST создавать ярлык в «Пуске» и запись в «Приложениях» Windows; ярлык на рабочем столе —
  по выбору пользователя.
- **FR-003**: Установщик MUST сам ставить недостающий компонент показа окна, если его нет в системе.
- **FR-004**: Удаление MUST убирать программу, ярлыки и пункт Проводника и НЕ трогать файлы пользователя; данные
  Sorter удаляются только по явной галочке.
- **FR-005**: Релизы MUST публиковаться на странице релизов проекта с установщиком и описанием изменений на русском.
- **FR-006**: Sorter MUST проверять обновления при запуске и затем не реже раза в сутки, пока открыт.
- **FR-007**: Найденное обновление MUST скачиваться в фоне без окон и звуков и ставиться при закрытии Sorter или
  по кнопке «Перезапустить»; Sorter MUST NOT перезапускаться сам. Единственное окно при установке — запрос
  разрешения администратора Windows (установка для всех пользователей).
- **FR-008**: Перед установкой обновления Sorter MUST дождаться завершения текущего хода и записи журнала.
- **FR-009**: Sorter MUST ставить только обновление, подписанное ключом проекта, и только если оно новее текущей
  версии.
- **FR-010**: В настройках MUST быть блок «Версия и обновления»: текущая версия, состояние, «Проверить сейчас»,
  «Перезапустить» (когда готово), переключатель «Проверять обновления» и «Что нового» — описание готового или
  последнего поставленного обновления. Внешний вид — по кадру HSettings.
- **FR-011**: Ошибки проверки и установки MUST показываться только в этом блоке, по-русски, с причиной и следующим
  шагом (FR-030 фичи 001); всплывающих окон с ошибками обновления нет.
- **FR-012**: Кроме проверки и скачивания обновлений Sorter MUST NOT делать сетевых запросов; при выключенной
  проверке — ни одного.
- **FR-013**: Установщик MUST добавлять пункт «Разобрать с Sorter» в контекстное меню папки в Проводнике — на значке
  папки и на пустом месте внутри открытой папки.
  В Windows 11 пункт виден под «Показать дополнительные параметры»; в основное меню Windows 11 он не встраивается.
- **FR-014**: Пункт MUST открывать Sorter с выбранной папкой как колодой и прежним столом; все проверки выбора
  колоды (существует, не совпадает со столом и не вложена в него) MUST действовать как в настройках.
- **FR-018**: Sorter MUST работать одним окном: повторный запуск (из «Пуска» или Проводника) выводит открытое окно
  вперёд; запуск с папкой переключает его на эту колоду.
- **FR-015**: Из окна, открытого пунктом Проводника, MUST можно сменить стол без захода в настройки.
- **FR-016**: Первый запуск MUST показывать плитки «Откуда брать видео» и «Куда раскладывать» с пояснениями.
- **FR-017**: Все данные Sorter (журнал, настройки, кэш, подсказки) MUST сохраняться при обновлении, переустановке
  и переходе с portable-копии.

### Key Entities

- **Релиз**: версия, дата, описание изменений («Что нового»), установщик, подписанный файл обновления.
- **Состояние обновления**: нет проверки / проверяется / последняя версия / скачивается (версия, доля) / готово
  к установке (версия) / ошибка (причина, когда повторить). Живёт, пока открыт Sorter.
- **Настройка «Проверять обновления»**: вкл/выкл, по умолчанию вкл.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Установка с нуля до открытого окна Sorter занимает не больше 1 минуты и 4 действий пользователя.
- **SC-002**: Новая версия доходит до пользователя без его участия: при открытом Sorter обновление готово к установке
  не позже чем через 10 минут после запуска (при сети от 10 Мбит/с).
- **SC-003**: Во время проверки и скачивания обновления смена карты по-прежнему 0,3 с или быстрее в 95 % случаев.
- **SC-004**: После обновления и переустановки сохраняются 100 % ходов журнала, настроек и примеров подсказок.
- **SC-005**: От правого клика по папке до карты на экране — не больше 5 с.
- **SC-006**: При выключенной проверке обновлений Sorter не делает ни одного сетевого запроса за сессию
  (служебное соединение WebView2 при старте — вне контроля, см. SC-007 фичи 001).
- **SC-007**: Обновление с чужой подписью или повреждённое не ставится ни в одном случае.

## Assumptions

- Образец — остальные приложения пользователя: установка для всех пользователей, русский язык
  без выбора, свой шаблон установщика как у Booked и Echo Studio, `latest.json` в релизах GitHub как у Booked.
- Репозиторий `stillmvd/sorter` на GitHub публичный, релизы качаются без входа.
- Данные Sorter уже лежат в `%APPDATA%\com.stillmvd.sorter` (фича 001), переносить их не нужно.
- Каналов (бета/стабильная) нет — одна линия релизов.
- Подпись установщика сертификатом разработчика не входит в фичу; SmartScreen при первом запуске установщика
  может предупредить — это ожидаемо.
- Принцип III конституции пересматривается: «установщик вместо portable; единственная сеть — проверка обновлений,
  выключаемая в настройках». Меняется через `/speckit-constitution` до плана.
- Разбор фотографий — не в этой фиче.
