# Quickstart: приёмка установщика и обновлений

## Подготовка

- `scripts/fetch-runtime.ps1` (ресурсы подсказок), ключ подписи в `~/.tauri/sorter.key`.
- Сборка: `$env:TAURI_SIGNING_PRIVATE_KEY = Get-Content ~/.tauri/sorter.key -Raw; pnpm tauri build`
  → `src-tauri/target/release/bundle/nsis/Sorter_<версия>_x64-setup.exe` и `.sig`.
- Тестовая колода — `G:\sorter-test\deck`, стол — `G:\sorter-test\table` (оригинал `G:\vk videos` не трогать).

## 1. Установка (US1, SC-001)

Запустить установщик 1.0.0 → мастер на русском, галочка ярлыка на рабочем столе → Sorter в «Пуске» и в
«Приложениях» (знак, версия, издатель). Открыть, разложить карту. Время до окна ≤ 1 мин, действий ≤ 4.

## 2. Обновление (US2, SC-002, SC-003, SC-007)

1. Собрать 1.0.1 с тем же ключом; положить установщик, `.sig` и `latest.json` в папку, поднять
   `python -m http.server 8765`.
2. Поставить 1.0.0, собранную с `--config` на `http://localhost:8765/latest.json`.
3. Запустить → настройки: «Скачивается 1.0.1» → «Готово — перезапусти, чтобы обновить», «Что нового».
   Во время скачивания замер смены карты (`%TEMP%\sc002.js`): p95 ≤ 300 мс.
4. Закрыть окно → UAC → следующий запуск 1.0.1, журнал и настройки на месте, блок «Установлено 1.0.1».
5. Подменить `.sig` чужой подписью → «Обновление отклонено: подпись не совпала», версия прежняя.
6. Отказать в UAC → работает прежняя версия, в блоке причина и «Перезапустить».
7. Остановить сервер → «Не удалось проверить — нет сети», раскладка работает.
8. Выключить «Проверять обновления» → сэмплер соединений (`Get-NetTCPConnection` по дереву процессов Sorter)
   за 3 мин не видит ничего, кроме служебного соединения WebView2 при старте.

## 3. Проводник (US3, SC-005)

1. Правый клик по `G:\sorter-test\deck` → «Показать дополнительные параметры» → «Разобрать с Sorter» → окно с
   колодой ≤ 5 с. То же — правый клик по пустому месту внутри папки.
2. Sorter открыт с другой колодой → пункт на новой папке → то же окно впереди, колода новая.
3. Пункт на `G:\sorter-test\table\Мемы` → объяснение про вложенность и выбор другого стола.
4. Выделить две папки → пункта нет.
5. Сменить стол из окна (по кадру холста) → карта ложится в новый стол.

## 4. Первый запуск (US4)

Удалить `%APPDATA%\com.stillmvd.sorter\` (копию сохранить) → плитки «Откуда брать видео» и «Куда раскладывать»
с пояснениями.

## 5. Удаление (US1)

«Приложения» → удалить без галочки данных → видео и стопки на месте, пункта Проводника нет. Поставить снова —
колода, стол, журнал, подсказки на месте.
