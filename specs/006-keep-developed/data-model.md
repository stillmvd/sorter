# Data Model: 006

Схема не меняется. Меняется жизненный цикл строк.

## card

- Ключ узнавания: `deck_path` + `lower(file_name)` + `size` + `mtime` (FR-002).
- `stage`: `new → meta → frames → embedded`, `broken` — только если файл открылся и не проявился.
  Недоступная папка колоды оставляет `new` (FR-012).
- `status`: `in_deck | deferred | placed | gone`. Новое: `gone → in_deck`, когда файл вернулся в папку; при совпадении
  `size` и `mtime` `stage` сохраняется, иначе `new`.
- Строки не удаляются ни при смене колоды, ни при выходе с проявки, ни по сроку (FR-001, FR-006).

## Кадры `cache/<card_id>/`

- Живут, пока есть карта в `frames | embedded`. Папка без такой карты — сирота, её убирает `tidy`.
- Карта в `frames | embedded` без папки → при открытии колоды `stage='new'`, `frames=0`, строка `embedding`
  удаляется (FR-009).

## fingerprint, dupe, embedding

- Не удаляются при смене колоды и выходе (FR-001).
- `clear_cache`: удаляются у всех карт, кроме карт открытой колоды. `fingerprint` — по путям этих карт, `dupe` — пары,
  где хотя бы один путь из них (FR-008).

## dupe_dismissed, example, move

- Решения пользователя и журнал: не трогаются ни очисткой кеша, ни выходом (FR-008). Чистка — только по
  `deck::surely_gone`, как сейчас.

## settings

- `hints_enabled` больше не сбрасывается при `choose_deck` (FR-005).
- `deck_path` пуст → проявщик не берёт карты (R3).
