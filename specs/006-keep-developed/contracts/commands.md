# Контракты команд Tauri: 006

Сигнатуры для фронта не меняются, меняется поведение.

| Команда | Было | Стало |
|---|---|---|
| `choose_deck(path)` | синхронная; держит основное соединение всё время сверки; при смене пути выключает подсказки и стирает старую колоду | `async`; под основным соединением только `settings` и сброс `paused`; сверка на своём соединении; кадры без папок → `new`; `wake`; `pending` → повтор у watcher; подсказки не трогает |
| `choose_table(path)` | синхронная, держит соединение на `piles::sync` | `async`, `piles::sync` на своём соединении, `wake` |
| `cancel_deck()` | стирает карты колоды и кадры, отвязывает колоду | только отвязывает колоду и будит проявщик; данные остаются |
| `clear_cache()` | все кадры, `stage` всех карт сбрасывается | кроме открытой колоды; плюс `embedding`, `fingerprint`, `dupe` этих карт; `dupe_dismissed`, `example` не трогает; ответ — освобождено байт |
| `cache_info()` | без изменений | без изменений |
| `get_state()` | `developing.ready` | без изменений: повторное открытие проявленной папки сразу даёт `ready` |
