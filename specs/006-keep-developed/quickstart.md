# Quickstart: проверка 006

Dev — по паспорту в `CLAUDE.md` (раздел «Стенды»), база — `SORTER_DATA` на тестовой папке, CDP 9225.

1. **Повторное открытие (SC-001, SC-002).** Колода `G:\vk videos` (187 видео) проявлена до конца → «Домой» → снова
   выбрать ту же папку. Ожидание: экрана проявки нет, первая карта сразу, `get_state().developing.ready === true`,
   в журнале проявщика 0 новых карт.
2. **Прерванная проявка (SC-003).** Новая папка → дождаться ~30 проявленных → Esc → та же папка. Ожидание: счётчик
   проявки продолжается с ~30, а не с 0.
3. **Перезапуск (SC-004).** Сценарии 1–2 после закрытия и запуска dev.
4. **Подсказки (FR-005).** Включить подсказки → сменить колоду на другую и обратно. Ожидание: подсказки включены.
5. **Изменённый файл (FR-002).** Поменять время изменения одного файла (`(Get-Item f).LastWriteTime = Get-Date`) →
   открыть колоду. Ожидание: проявляется 1 файл.
6. **Пропавшие кадры (FR-009).** Удалить одну папку `cache/<id>` → открыть колоду. Ожидание: 1 карта проявляется
   заново, ошибок нет.
7. **Очистка (FR-007, FR-008).** Настройки → «Очистить кэш» дважды. Ожидание: размер падает, карты открытой колоды
   остались проявленными, отметки «не дубли» на месте.
8. **Окно не замирает (FR-011).** Открыть `G:\sorter-test\big` (5000) и во время сверки нажимать переключатели.
   Ожидание: отклик сразу.
9. **Автотесты.** `pnpm run check` (при запущенном dev — `CARGO_TARGET_DIR=target-test`) → `pnpm build`.
