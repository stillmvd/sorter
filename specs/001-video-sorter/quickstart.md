# Quickstart: проверка Sorter

## Подготовка

- Копия колоды: `robocopy "G:\vk videos" "G:\sorter-test\deck" *.mp4` — оригинал не трогать.
- Стол: `G:\sorter-test\table` с папками `Мемы`, `Музыка`, `Животные`; второй стол на другом диске
  (например `C:\sorter-test\table`) — для переноса между дисками.
- Dev: `pnpm tauri dev`. Релиз: `pnpm tauri build --no-bundle` → `src-tauri\target\release\sorter.exe`.
- Автотесты ядра: `cargo test --manifest-path src-tauri/Cargo.toml`.

## Сценарии

| # | Шаги | Ожидаемо |
|---|------|----------|
| 1 | Первый запуск, выбрать колоду и стол | 187 карт, 3 стопки + «Корзина», клавиши 1–3, Delete |

| 3 | Ctrl+Z × 2, затем забрать 5-й ход из журнала | ровно эти файлы вернулись в колоду под своими именами |
| 4 | Положить файл, имя которого уже есть в стопке | в стопке оба: `имя.mp4` и `имя (2).mp4` |
| 5 | Delete на карте, затем Ctrl+Z | файл в корзине Windows, затем снова в колоде |
| 6 | Стол на другом диске, положить карту, во время копирования снять задачу процессом | при запуске ход доведён или откатан; файл ровно в одном месте, не битый |

| 8 | Скопировать 10 новых mp4 в колоду при открытом приложении | карты появляются в конце колоды, проявляются |

| 10 | Стол: отметить 2, напечатать «Концерты», Shift+Enter | папка создана, файлы в ней, стопка в ряду с клавишей |
| 11 | Перетащить карту на стопку; перетащить мимо | ход `drag`; мимо — карта вернулась, хода нет |

| 13 | Горизонтальное видео после вертикального | карта поворачивается за 320 мс; с уменьшением движения — сразу |
| 14 | Видео, которое не играет (HEVC/mkv) | плёночный режим, Ctrl+O открывает в MPC |
