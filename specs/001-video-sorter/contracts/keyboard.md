# Contract: клавиатура и мышь

Внешний контракт с пользователем. Одинаков во всех версиях; изменение — только через спеку.

## Колода

| Клавиша | Действие |
|---------|----------|
| `1`–`9`, `Q`…`P` (назначенные) | положить карту в стопку |
| `Delete` | положить в «Корзину» |
| любая буква/цифра без стопки, кириллица | начать поиск стопок (фокус в поле, символ добавлен) |
| `/` | фокус в поиск |
| `Enter` | поиск не пуст → первая подходящая стопка; пуст → подсказанная (если есть) |
| `Shift+Enter` | создать стопку из текста поиска и положить туда |
| `Esc` | очистить поиск |
| `Tab` | в конец колоды |
| `Ctrl+Z` | забрать последний ход |
| `Пробел` | пауза / воспроизведение |
| `←` `→` | кадр плёнки назад / вперёд (видео перематывается к кадру) |
| `M` | звук вкл/выкл (если `M` не назначена стопке; иначе `Ctrl+M`) |
| `Ctrl+O` | открыть видео в системном плеере (для карт, которые не играют в приложении) |
| `Ctrl+1` / `Ctrl+2` | режим «Колода» / «Стол» |

Когда поиск в фокусе, клавиши стопок печатают текст, а не кладут; `Esc` возвращает режим клавиш.
Правило для раскладки: буквы стопок сравниваются по физической клавише (`KeyboardEvent.code`), поэтому
работают и в русской раскладке.

## Стол

| Ввод | Действие |
|------|----------|
| клик по плёнке | отметить / снять |
| `Shift`+клик | отметить диапазон |
| `Ctrl+A` | отметить все на экране |
| наведение | проигрывать эту плёнку (без звука) |
| клавиша стопки, `Delete`, поиск + `Enter`, `Shift+Enter` | как в колоде, для всех отмеченных |
| `Esc` | поиск не пуст → очистить; пуст → снять отметки |

## Мышь (обе вкладки)

- Перетаскивание карты (колода) или отмеченных плёнок (стол) на стопку — ход `drag`. Стопка под курсором — подсветка
  «похоже». Отпускание мимо — возврат за 200 мс, хода нет.
- Клик по стопке — положить (колода) / положить отмеченные (стол).
- Все кнопки интерфейса доступны с `Tab` и `Enter` при фокусе на них (Tab как «в конец» работает, когда фокус
  на карте/странице, а не на кнопке).
