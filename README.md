# Sorter

Раскладка видео и фото по папкам для Windows 11. Каждый файл — карта, каждая папка стола — стопка. Смотришь карту,
жмёшь клавишу стопки — файл переезжает туда. Любой ход можно забрать обратно.

## Возможности

- **Колода** — по одному файлу: видео с раскадровкой, фото со сведениями (дата, камера, разрешение); **стол** — пачкой,
  с перемоткой наведением.
- Фото JPG, PNG, WebP и GIF с поворотом по EXIF; фильтр «Все / Видео / Фото» для колоды и стопок.
- Серии: похожие снимки, сделанные подряд, — одна карта и один ход; лишние кадры можно сразу убрать в Корзину.
- Клавиши стопок, поиск стопки по названию, новая стопка на ходу.
- Подсказки: Sorter учится на разложенном и предлагает стопку по кадрам — считается на этом компьютере.
- Дубли: точные копии, пережатые, обрезанные и кадрированные видео и фото по колоде и всем стопкам вместе с их
  подпапками, сравнение бок о бок.
- Журнал ходов по дням, «Забрать» у каждого хода; «удаление» — только в корзину Windows.

## Установка

Скачай `Sorter_<версия>_x64-setup.exe` со страницы [релизов](https://github.com/stillmvd/sorter/releases/latest)
и запусти. Windows может предупредить о неизвестном издателе — «Подробнее» → «Выполнить в любом случае».

Новые версии Sorter проверяет при запуске, раз в час и когда возвращаешься в окно, скачивает в фоне и предлагает
«Перезапустить» — Windows один раз спросит разрешение. «Позже» оставляет значок со стрелкой в шапке окна.

## Проводник

Правый клик по папке (или по пустому месту внутри неё) → «Показать дополнительные параметры» →
**«Разобрать с Sorter»**. Папка откроется как колода, стол останется прежним — его можно сменить прямо в окне.

## Данные

Журнал, настройки, раскадровки и примеры для подсказок лежат в `%APPDATA%\com.stillmvd.sorter`. В папки с файлами
Sorter служебных файлов не пишет. При удалении программы данные остаются, если не отметить «Удалить данные».

## Сборка

```powershell
pnpm install
./scripts/fetch-runtime.ps1   # ONNX Runtime, DirectML и модель DINOv2 для подсказок
pnpm tauri dev
pnpm tauri build              # установщик в src-tauri/target/release/bundle/nsis
pnpm run check                # tsc, clippy, тесты Rust
pnpm release                  # проверки, версия по коммитам, сборка, тег, публикация в GitHub Releases
```

Релизы — по стандарту [tauri-ship](https://github.com/stillmvd/tauri-ship): версия только в `package.json`,
описание — из conventional-коммитов.
